# Status

Status: done
Updated: 2026-08-31

The `Status:` header line every flow and doc carries. Listed in lifecycle order, `ref` last since it sits off the main line.

| Status | Applies to | Meaning |
| --- | --- | --- |
| wip | flow, doc | Ideas being gathered. Not worked out yet. |
| draft | flow | Being worked out. The shape is there, the detail is not settled. |
| ready | flow | Settled and ready to execute in a code repo. |
| done | flow, doc | A flow is built in at least one repo. A doc describes the setup as it is. |
| ref | flow | A strategy that was evaluated and not taken. The one that was taken sits beside it. |
